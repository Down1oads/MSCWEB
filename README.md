# MSCWEB

An unofficial browser port of *My Summer Car* (runs entirely in your browser).

- Ported by Down1oads.
- The game, its art, audio and code belong to its original developer (Amistech Games / Johannes Rojola). This is a fan port, not affiliated with or endorsed by them. If you are the owner and want it taken down, open an issue and it will be removed.
- Graphics are slightly reduced (simpler shaders, smaller textures) so the game fits in a browser; game code and physics are the original.
- Known gaps: a few music tracks are silent, the radio/CD player cannot read your own music, no Steam features. Use a desktop browser with a GPU; the first load downloads about 550 MB, later visits use the browser cache where available.
